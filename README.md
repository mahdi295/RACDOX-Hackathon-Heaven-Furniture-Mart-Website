# Heaven Furniture Mart

Heaven Furniture Mart is a luxury bespoke furniture brand based in Agrabad, Chattogram, Bangladesh. This project is a premium marketing and lead-generation website for the showroom, showcasing custom living, bedroom, dining, office, and space-saving furniture solutions.

The site is built to reflect the brand’s positioning: refined craftsmanship, tailored design, showroom-first trust, and a direct consultation-to-WhatsApp conversion flow for client inquiries.

## Website purpose
This website presents the business in a modern, premium way for:
- attracting homeowners, interior-conscious buyers, and businesses
- showing furniture collections and custom possibilities
- communicating craftsmanship and showroom credibility
- driving consultations through WhatsApp and direct contact
