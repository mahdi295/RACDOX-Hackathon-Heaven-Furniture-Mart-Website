# Heaven Furniture Mart

Bespoke luxury furniture website — Agrabad, Chattogram. TanStack Start (React 19, SSR) + Tailwind CSS v4 + shadcn/ui.

## Development
```sh
npm install
npm run dev      # http://localhost:3000
```

## Build & deploy
```sh
npm run build
npm run lint
```
See `docs/DEPLOYMENT.md` for hosting instructions.

Full documentation set — content editing, asset guide, testing checklist, deployment — lives in `docs/`.

Latest audit/bugfix pass: see `REBUILD_CHANGELOG.md` (bug list) and `docs/DEPLOYMENT.md` (Cloudflare deploy troubleshooting).
