# Testing and QA Guide

This website should be checked in a realistic business-use flow before launch. The main focus is product trust, mobile readability, and lead conversion.

## Core quality checks
Run the following checks on the site before presenting or publishing it:

- homepage loads correctly
- navigation works on desktop and mobile
- all collection cards and links behave as expected
- contact form validates correctly
- WhatsApp link opens with the correct prefilled details
- phone and email links work
- maps link points to the showroom location
- social links open to the correct channels
- images load properly and are not broken

## Recommended browser check list
Test on:
- desktop width
- tablet width
- mobile width

Check for:
- no stretched or distorted hero images
- clean spacing and typography
- readable text on all backgrounds
- mobile menu open/close behavior
- gallery functionality and scroll behavior
- no broken visual overlays or clipped content

## Content validation
Before launch, verify that all of the following remain accurate:
- brand name and spelling
- phone number and WhatsApp number
- email address
- showroom address
- product category names
- founder and leadership details
- any milestone or award text

## Production signoff checklist
- [ ] Homepage looks premium and aligned with the brand
- [ ] Collections are visually balanced and readable
- [ ] Contact flow is clear and direct
- [ ] Mobile experience feels polished
- [ ] Page metadata is reviewed
- [ ] The final domain and deployment are active

## Performance check
This is a design-heavy marketing website, so the main concern is image performance. Keep the visual quality high while maintaining smooth browsing, especially on mobile devices.

## Final QA principle
The site should not just look good; it should also feel trustworthy and believable as a real luxury showroom. If a visitor can quickly understand the brand, see the product quality, and reach the business with minimal friction, the website is performing as intended.
